# Claude Certification Study Notes

Personal study notes and reference material for Anthropic Claude certification preparation, beginning with **Claude Certified Architect - Foundations (CCA-F)**. The repository may also contain notes for related Claude certifications, such as CCA-P.

## Contents

- [CCA-F Study Notes](CCA-F_Study_Notes.md): Exam concepts, decision rules, worked questions, and lessons learned.
- [`docs/`](docs/): Official exam guides, policies, terms, and supporting reference PDFs.

## Using These Notes

1. Start with the CCA-F exam guide in [`docs/`](docs/) to understand the exam scope.
2. Review [CCA-F Study Notes](CCA-F_Study_Notes.md) alongside the guide.
3. Use the examples and rule-of-thumb tables to practice selecting an appropriate agent workflow or tool.

## Contributing Notes

Keep additions focused and easy to review:

- Group notes under clear Markdown headings.
- Capture the reasoning behind an answer, not only the answer itself.
- Mark incorrect approaches and explain why they fail.
- Avoid including confidential exam content or material that violates Anthropic's certification policies.

## Disclaimer

These are personal study notes. They are not official Anthropic documentation and do not guarantee certification outcomes.
